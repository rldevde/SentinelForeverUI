# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| latest (main) | yes |
| older releases | fixes land in the next release |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-relevant
problems (e.g. addon-message spoofing, insecure frame/secure-handler
usage, saved-variable corruption that affects other addons).

Report them privately via:

- Bugtracker: https://xrl-dev.de/bugtracker (mark the ticket as security)
- Or the contact listed on https://xrl-dev.de/

You can expect an acknowledgement within a few days. Fixes are released
as soon as possible and credited in the changelog if you want.
